1. ¿Qué es y qué problema resuelve?

CourtManager Pro es el sistema operativo de utilería de un club profesional: plantilla, tallas, inventario, solicitudes, viajes, lavandería, material médico, alertas y checklists de partido — en una sola aplicación web.

Sustituye Excel + WhatsApp + conocimiento individual por un punto de verdad con trazabilidad, roles y alertas automáticas.

4. Seguridad — lo que un pentest verá

Seguridad es prioritaria. El sistema aplica tres capas reales en producción:

  1. Middleware: sin sesión → login / 401; registro cerrado; crons con secreto.
  2. APIs: usuario obligatorio + pertenencia a equipo (anti-IDOR).
  3. Base de datos: Row Level Security por equipo en PostgreSQL (Supabase).

Qué NO se vende como hecho

  • Certificación ISO/SOC2 (no incluida en el repositorio).
  • SSO corporativo Azure AD / Okta (fase 2 si TI lo exige).
  • Integración nativa ERP/CRM (posible vía APIs; no conector listo).

5. Alcance del piloto recomendado (4–8 semanas)

  • Inventario + tallas + solicitudes + alertas.
  • Almacén / movimientos y checklist pre-partido.
  • 3–5 KPI: tiempo de preparación, roturas de stock, % solicitudes a tiempo.
  • Usuarios: utillería + 1 perfil médico + 1 consulta (además del demo ATM).

6. Fortalezas (ordenadas)

  1. Dominio real de utilería de élite (ciclo completo).
  2. Seguridad en capas + roles + trazabilidad.
  3. Pack y sync específicos de ATM.
  4. Arquitectura evolucionable (APIs, multi-equipo).
  5. UX orientada al utillero (baja curva de formación).

8. Conclusión para dirección

CourtManager Pro es una buena inversión de piloto: digitaliza la utilería del primer equipo con producto ya adaptado a ATM, reduce riesgos operativos y de control, y permite evaluar con una cuenta limitada sin abrir el acceso de superadmin. La seguridad está diseñada para resistir pruebas de acceso indebido; los puntos abiertos son conocidos y planificables.

Próximo paso propuesto

  1. Activar demo ATM en el entorno de evaluación.
  2. Sesión de 60–90 min con utillería / Atleti Lab.
  3. Decisión de piloto formal con KPI y calendario.
