## Vídeo: ¿MP4 o HTML por correo?

**No envíes el HTML por correo.** La mayoría de clientes de email no ejecutan el vídeo ni la sincronización audio–pantalla.

**Opciones recomendadas (en orden):**

1. **MP4 adjunto** (ideal si pesa &lt; 15–20 MB) — graba `VIDEO-PROMO.html` a pantalla completa con OBS o CapCut.
2. **Enlace** a Google Drive / WeTransfer / Dropbox (mejor si el MP4 es grande).
3. **YouTube o Vimeo en modo no listado** — enlace en el correo; aspecto muy profesional.
4. **PDF del dossier + enlace al vídeo** — lo más habitual en outreach B2B.

El HTML sirve para **previsualizar y grabar** en tu ordenador, no como archivo de envío.
